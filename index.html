FAQ

Частые вопросы и ошибки

Решения самых распространённых проблем при работе с сервисом.

⚠️

Основной домен не открывается или запрос висит

В начале Docs переключи домен с «Основной» на «Резервный», затем заново скопируй команду: все endpoint'ы и скрипты ниже обновляются вместе с выбором. Полностью перезапусти клиент.

🔑

После setup клиент просит войти или не видит CVC_API_KEY

Сначала полностью закрой и заново открой клиент. Для VS Code Remote, SSH, Cursor Remote, VPS и server workspace запускай setup на удалённой машине, где работает extension host, а не на ноутбуке. Если VS Code Remote не перечитал окружение, выполни команду ниже на удалённой машине и переподключись.

pkill -f 'codex app-server|[.]vscode-server/.*/server/out/bootstrap-fork --type=extensionHost'
🚫

401, Incorrect API key или запрос уходит на api.openai.com

Клиент всё ещё обращается напрямую в OpenAI, поэтому ключ CheapVibeCode там не принимается. Запусти setup на машине, где реально работает клиент, и перезапусти его. Если 401 появился после переустановки, один раз выполни «Отключиться от проекта», затем снова запусти setup: это уберёт старый OpenAI auth/config.

🔍

Модель не появилась или клиент пишет Model not found

Сверь точный Model ID со списком моделей в Docs или ответом /v1/models и проверь, разрешена ли модель выбранному ключу. В Codex и ZCode используй обычный ID, в OpenCode и Kimi — cheapvibecode/<model>, в Cursor — <model>-cursor. После изменения модели или ключа перезапусти клиент. Отключённая модель временно скрывается из каталога.

📊

Что означают 429, 502/503/504, 524 и capacity_unavailable?

429 означает ограничение частоты: дождись Retry-After и уменьши число параллельных запросов. 502/503/capacity_unavailable означают временную недоступность upstream или свободных аккаунтов. При 524 сначала поменяй домен с «Основной» на второй — «Резервный» — в начале Docs, заново скопируй команду настройки и полностью перезапусти клиент. 504/upstream_timeout означает, что upstream не успел ответить: подожди, повтори с backoff один раз и при необходимости выбери другую доступную модель. Если ошибка повторяется, передай строку из логов поддержке.
